# Daily Robotics & AI Learning Workflow

**Objective:** Build strong foundations in Robotics, AI, Embedded Systems, and Autonomous Systems through consistent daily learning and project development.

---

# Daily Workflow

## 1. Plan the Day (10–15 min)

Create today's note:

```
notes/daily/YYYY-MM-DD.md
```

Write:

- Today's topic
- Goals
- Expected outcome

Example:

- ROS 2 Topics
- Understand Publishers & Subscribers
- Control TurtleBot

---

## 2. Learn Theory (45–60 min)

Read official documentation first.

Priority:

1. ROS 2 Documentation
2. Webots Documentation
3. Foxglove Documentation
4. OpenCV Documentation
5. PyTorch Documentation

Take concise notes.

---

## 3. Hands-on Practice (2–3 hrs)

Apply what you learned.

Examples:

- Run commands
- Create packages
- Write nodes
- Launch simulations
- Test sensors
- Debug issues

Never stop at following tutorials—experiment.

---

## 4. Experiment (30–60 min)

Try variations.

Examples:

- Change robot speed
- Modify controller values
- Publish different messages
- Change simulation parameters
- Observe behavior

Ask yourself:

"What happens if I change this?"

---

## 6. Update Topic Notes

If you completed a topic, update:

```
notes/
├── ros2/
├── webots/
├── foxglove/
├── slam/
├── nav2/
├── opencv/
├── ai_ml/
└── ...
```

These are your long-term study notes.

---

## 7. Update Project Documentation

Every project should contain:

```
project_name/
│
├── README.md
├── docs/
├── screenshots/
├── launch/
├── config/
├── src/
└── resources/
```

README should include:

- Objective
- Technologies
- Folder structure
- How to run
- Results
- Future improvements

---

## 8. Update Troubleshooting Log

Whenever you solve an issue:

```
notes/troubleshooting/
```

Record:

- Problem
- Cause
- Solution
- Verification
- Prevention

---

## 9. Git Commit (Project Work)

If you made meaningful project changes:

```
git add .
git commit -m "Describe today's work"
git push
```

---

## 10. Prepare Tomorrow

Write tomorrow's objective before stopping.

Example:

- Learn TF2
- Build publisher node
- Understand LiDAR

---

# Guiding Principles

- Learn concepts before memorizing commands.
- Build something every day, even if it's small.
- Experiment instead of only following tutorials.
- Document what you learn and what you fix.
- Keep projects organized and reproducible.
- Review your progress every week.
- Focus on steady improvement rather than rushing through topics.
